# Task 01: normalize_whitespace

Implement `normalize_whitespace(text)`. Return the input string with each run of whitespace (spaces, tabs, or newlines) replaced by one ordinary space, and with leading and trailing whitespace removed. Empty or all-whitespace input returns `""`.

Examples:
- `normalize_whitespace("  red\\tblue  ") == "red blue"`
- `normalize_whitespace("a\\n\\n b") == "a b"`

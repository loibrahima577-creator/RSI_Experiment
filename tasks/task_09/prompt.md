# Task 09: sort_by_frequency

Implement `sort_by_frequency(words)`. Return each distinct input word once, ordered by decreasing number of occurrences in the input. Break ties by ascending case-sensitive lexicographic order. Words are strings; comparisons are case-sensitive.

Examples:
- `sort_by_frequency(["pear", "fig", "pear", "plum", "fig"]) == ["fig", "pear", "plum"]`
- `sort_by_frequency(["b", "a"]) == ["a", "b"]`

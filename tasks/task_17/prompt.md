# Task 17: transpose_matrix

Implement `transpose_matrix(matrix)`. Return the transpose of a rectangular matrix represented as a list of row lists. The input is not mutated. An empty matrix returns `[]`; a matrix with rows but zero columns returns `[]`. Raise `ValueError` if row lengths differ.

Examples:
- `transpose_matrix([[1, 2, 3], [4, 5, 6]]) == [[1, 4], [2, 5], [3, 6]]`
- `transpose_matrix([[1], [2]]) == [[1, 2]]`

# Task 14: format_phone

Implement `format_phone(digits)`. Given a string containing exactly 10 ASCII digits, return it formatted as `(AAA) BBB-CCCC`. Raise `ValueError` for any other length or for any non-digit character. Do not strip punctuation or whitespace.

Examples:
- `format_phone("4155552671") == "(415) 555-2671"`
- `format_phone("0000000000") == "(000) 000-0000"`

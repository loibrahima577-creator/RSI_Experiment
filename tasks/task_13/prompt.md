# Task 13: days_between

Implement `days_between(date_a, date_b)`. Each argument is a valid Gregorian date in `YYYY-MM-DD` form. Return the absolute number of calendar days between the two dates. Inputs are valid and years are from 1 through 9999.

Examples:
- `days_between("2024-01-01", "2024-01-04") == 3`
- `days_between("2024-03-01", "2024-02-28") == 2`

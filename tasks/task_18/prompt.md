# Task 18: spiral_order

Implement `spiral_order(matrix)`. Return all elements of a rectangular matrix in clockwise spiral order, starting at the top-left corner. Return `[]` for an empty matrix or a matrix with zero columns. The input is rectangular.

Examples:
- `spiral_order([[1, 2, 3], [4, 5, 6]]) == [1, 2, 3, 6, 5, 4]`
- `spiral_order([[1], [2], [3]]) == [1, 2, 3]`

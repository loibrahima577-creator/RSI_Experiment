# Task 02: rotate_list

Implement `rotate_list(items, k)`. Return a new list containing `items` rotated right by `k` positions. Positive `k` rotates right, negative `k` rotates left, and values larger than the list length wrap around. Do not mutate `items`.

Examples:
- `rotate_list([1, 2, 3, 4], 1) == [4, 1, 2, 3]`
- `rotate_list([1, 2, 3], -1) == [2, 3, 1]`

# Task 03: unique_preserve_order

Implement `unique_preserve_order(items)`. Return a new list containing the first occurrence of each distinct item, in input order. Items are hashable and equality follows Python's normal `==` behavior.

Examples:
- `unique_preserve_order([3, 1, 3, 2, 1]) == [3, 1, 2]`
- `unique_preserve_order([]) == []`

# Task 06: intersection_labels

Implement `intersection_labels(first, second)`. Return the labels found in both sequences, using their spelling from `first` and considering each shared label once. The result follows the order in which labels occur in `first`.

Examples:
- `list(intersection_labels(["oak", "ash"], ["ash", "elm"])) == ["ash"]`.
- `list(intersection_labels(["a", "b", "c"], ["c", "a"]))` contains `a` and `c`.

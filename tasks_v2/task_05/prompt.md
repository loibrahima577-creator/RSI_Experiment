# Task 05: interleave

Implement `interleave(left, right)`. Combine two equally sized sequences by taking one item from `left`, then one from `right`, repeating until both are exhausted.

Examples:
- `list(interleave([1, 2], ["a", "b"])) == [1, "a", 2, "b"]`.
- `list(interleave([7], [8])) == [7, 8]`.

# Task 09: find_products

Implement `find_products(products, query)`. Each product is a dictionary with a `name` string and numeric `score`. Return products whose names contain `query`, ordered from highest score to lowest.

Examples:
- For products named `"Red mug"` and `"Blue mug"`, query `"mug"` selects both.
- If their scores are 8 and 3, the score-8 product comes first.

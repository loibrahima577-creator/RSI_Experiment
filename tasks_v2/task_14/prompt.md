# Task 14: sort_events

Implement `sort_events(events)`. Each event is a dictionary with an ISO date-time string in `time` and any other fields. Return the events ordered from earliest time to latest.

Examples:
- An event on `2023-01-01T09:00:00` comes before one on `2023-01-02T09:00:00`.
- The result contains the same event fields as the input records.

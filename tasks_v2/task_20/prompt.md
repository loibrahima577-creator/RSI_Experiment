# Task 20: count_islands

Implement `count_islands(grid)` for a rectangular grid of `0` water and `1` land. Count land components connected horizontally or vertically; diagonal contact does not connect cells.

Examples:
- `count_islands([[1, 0], [0, 1]]) == 2`.
- `count_islands([[1, 1], [0, 1]]) == 1`.

# Task 17: matrix_multiply

Implement `matrix_multiply(left, right)`. Multiply two rectangular matrices represented by rows of numbers and return the product matrix. The number of columns in `left` matches the number of rows in `right` for valid inputs.

Examples:
- `matrix_multiply([[1, 2]], [[3], [4]])` produces a one-row matrix containing `11`.
- `matrix_multiply([[2]], [[5]])` produces a one-cell matrix containing `10`.

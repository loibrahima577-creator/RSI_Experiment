# Task 03: rotate_items

Implement `rotate_items(items, k)`. Return the sequence shifted right by `k` positions, wrapping items that pass the end back to the beginning. `k` is a nonnegative integer.

Examples:
- `list(rotate_items([1, 2, 3, 4], 1)) == [4, 1, 2, 3]`.
- `list(rotate_items([1, 2, 3], 3)) == [1, 2, 3]`.

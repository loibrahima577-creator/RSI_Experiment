# Task 16: merge_ranges

Implement `merge_ranges(ranges)`. Each range has a start and end. Sort ranges by start and combine ranges that overlap or meet at an endpoint. Return the resulting ranges in increasing order.

Examples:
- `merge_ranges([[1, 4], [3, 7], [10, 12]])` produces ranges `[1, 7]` and `[10, 12]`.
- `merge_ranges([[2, 3], [3, 5]])` produces one range from 2 through 5.

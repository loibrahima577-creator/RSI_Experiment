# Task 18: shortest_path

Implement `shortest_path(graph, start, goal)`. The graph maps each node to its neighbors and is undirected. Return a path with the fewest edges from `start` to `goal`, including both endpoints. Neighbor lists may be in any order.

Examples:
- In a graph with edges `A-B`, `B-C`, and `A-C`, the path from `A` to `C` uses one edge.
- A path from a node to itself has no edges.

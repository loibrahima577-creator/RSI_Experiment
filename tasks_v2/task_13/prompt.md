# Task 13: nearest_date

Implement `nearest_date(dates, target)`. Dates use ISO `YYYY-MM-DD` form. Return the input date closest in calendar days to `target`.

Examples:
- `nearest_date(["2024-01-01", "2024-01-09"], "2024-01-08") == "2024-01-09"`.
- `nearest_date(["2020-02-29"], "2020-03-01") == "2020-02-29"`.
